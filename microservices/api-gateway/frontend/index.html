Microservices Architecture

  • API Gateway: NGINX reverse proxy serving this frontend
  • Auth Service: User authentication and authorization (3 replicas)
  • Doctor Service: Doctor profiles and availability (3 replicas)
  • Patient Service: Patient profiles and medical history (4 replicas)
  • Pharmacy Service: Pharmacy management (2 replicas)
  • Scheduling Service: Appointment scheduling (4 replicas)
  • Inventory Service: Medicine catalog and stock (3 replicas)
  • Notification Service: Alerts and notifications (2 replicas)

Total Pods: 25 backend + 4 gateway = 29 application pods
